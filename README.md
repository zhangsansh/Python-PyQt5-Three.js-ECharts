# 银行用户信用风险评估可视化大屏

基于 **Python 机器学习** 与 **PyQt5** 桌面框架开发的银行用户信用风险评估与可视化分析系统。系统以深色数据大屏风格呈现，融合 **Three.js** 三维建模、**ECharts** 多维图表、操作日志归档与 SQLite 持久化，支持多标签特征分析、历史融合评估、参数配置与按日期的数据管理。

## 1. 项目简介

本程序面向银行（或类金融场景）的**用户信用风险评估**演示与教学可视化需求，核心能力包括：

- 基于模拟银行客户特征数据，训练信用风险多分类模型（低 / 中 / 高风险）；
- 在主分析大屏中，用 **四个 Three.js 三维区域**展示分析前 / 分析后、单标签分析前 / 分析后的样本分布；
- 支持鼠标旋转、平移、缩放三维场景，并**单击样本点**查看详细特征与风险信息；
- 右侧实时展示准确率、召回率、精确率、F1 及识别内容、指标图表；
- 通过顶部导航切换：**分析大屏、图表分析、日志记录、参数设置、数据管理、系统配置**；
- 分析结果、日志、截图、参数快照按**日期自动归档**，并同步写入 **SQLite** 数据库。

> 说明：当前版本使用程序内**合成样本数据**进行训练与演示，便于离线运行与课堂展示；特征含义与评估流程与真实风控建模思路一致，便于扩展接入真实业务数据。

## 2. 功能说明

### 2.1 分析大屏（主页面）

| 能力           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| 四区域 3D 建模 | 左上：分析前整体模型；右上：分析后整体模型；左下 / 右下：当前选中标签的分析前 / 后分布 |

| 多标签选择     | 下拉框、快速选择按钮、标签卡片「选中」勾选，控制参与分析与当前显示的标签 |
| 标签数量控制   | 数字框 / +/- / 应用数量 / 显示全部 / 刷新                    |

### 2.2 图表分析页

可自由勾选并组合多种 **ECharts** 图表样式，用于分析评估相关统计数据，包括但不限于：

- 渐变堆叠面积图  
- 带背景色的柱状图  
- 柱状图标签旋转  
- 嵌套环形图  
- 饼图纹理（玫瑰图风格）  
- 数据聚合 / 聚合过程可视化  
- 线性回归散点与拟合线  
- 单轴散点图  
- AQI 风格雷达图（模型健康度）  
- 盒须图  

### 2.3 日志记录页

- 查看操作日志、识别分析记录；
- 按日期筛选；
- 预览当日识别截图；
- 打开图片存储目录。

### 2.4 参数设置页

可调整随机森林等模型超参数及显示相关配置，例如：

- `n_estimators`、`max_depth`、`min_samples_split`
- `random_state`、`test_size`、`n_samples`
- 正文字号、标题字号  

保存后写入配置文件，并生成当日参数快照（文件 + 数据库）。

### 2.5 数据管理页

- 按日期浏览分析记录、参数快照、当日文件；
- 导出当日摘要 JSON；
- 查看 SQLite 数据库概况；
- 打开存储目录。

### 2.6 系统配置页

- 配置日志目录、图片目录、综合存储目录、SQLite 数据库路径；
- 支持相对路径或绝对路径；
- 一键创建目录（含当日子目录）。

### 2.7 通用界面特性

- 深色主题，消除默认白底；
- 全局约**六号字**显示；
- 窗口可用鼠标拖拽边框调整大小，启动时初始尺寸**适应屏幕可用区域**；
- 主分析区与右侧指标区可通过分割条调整比例。

## 4. 机器学习算法说明

本项目机器学习部分主要基于 **scikit-learn** 实现，流程如下。

### 4.1 特征体系（标签）

模拟银行用户信用相关特征（可多选参与训练）：

| 字段 Key         | 中文名称 | 含义简述         |
| ---------------- | -------- | ---------------- |
| `income`         | 收入水平 | 客户收入能力     |
| `debt_ratio`     | 负债比率 | 负债相对收入压力 |
| `credit_history` | 信用历史 | 信用积累年限等   |
| `employment`     | 就业年限 | 工作稳定性       |
| `age`            | 年龄     | 生命周期特征     |
| `loan_amount`    | 贷款额度 | 申请金额规模     |
| `num_accounts`   | 账户数量 | 账户活跃/分散度  |
| `payment_delay`  | 逾期次数 | 历史违约行为     |

风险标签为三分类：

- **0**：低风险  
- **1**：中风险  
- **2**：高风险  

### 4.2 数据生成

使用 NumPy 按统计分布合成特征，并根据负债率、逾期次数、收入、信用历史、就业年限、贷款收入比等规则构造风险评分，再映射为三类标签，用于可复现的演示训练。

### 4.3 主要算法与处理步骤

| 步骤           | 算法 / 方法                                                  | 说明                                                         |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 划分数据集     | `train_test_split`                                           | 按配置的 `test_size` 划分训练/测试集，支持分层抽样           |
| 标准化         | `StandardScaler`                                             | 对特征做零均值单位方差缩放                                   |
| 主分类器       | **RandomForestClassifier**（随机森林）                       | 集成多棵决策树，支持 `class_weight='balanced'`，输出风险类别与特征重要性 |
| 辅助建模       | **GradientBoostingClassifier**（梯度提升）                   | 用于强化“分析后”三维表征与概率特征构造                       |
| 三维降维       | **PCA**（主成分分析）                                        | 将高维特征投影到 3D；特征不足时自动补维，保证三维可视化可用  |
| 评估指标       | `accuracy_score` / `recall_score` / `precision_score` / `f1_score` | 准确率、召回率、精确率、F1（加权平均）                       |
| 混淆矩阵与报告 | `confusion_matrix` / `classification_report`                 | 分类细节与各类别表现                                         |

### 4.4 分析模式

1. **仅当前分析（默认）**  
   只使用本次训练与评估结果展示，不融合历史批次。

2. **结合历史记录分析**  
   从 SQLite 读取历史指标，与当前准确率、召回率等进行加权融合（当前权重更高），用于对比“当前 + 历史”的综合表现。

### 4.5 可调模型参数（参数设置页 / settings.json）

- `n_estimators`：随机森林树的数量  
- `max_depth`：树的最大深度  
- `min_samples_split`：内部节点再划分所需最小样本数  
- `random_state`：随机种子，保证可复现  
- `test_size`：测试集比例  
- `n_samples`：合成样本数量

## 5. 环境要求与安装

### 5.1 建议环境

- Windows 10 / 11（当前主要验证环境）


主要依赖见 `requirements.txt`：

- PyQt5、PyQtWebEngine  
- numpy、pandas、scikit-learn

```bash
py -3 -m pip install PyQtWebEngine
```

## 7. 操作流程

### 7.1 标准评估流程（推荐）

1. **启动程序**  
   运行 `py -3 main.py`。

2. **选择分析标签**  
   - 在多标签区域用「选中」勾选要参与分析的特征；或  
   - 设置「标签数量」后点「应用数量」；或  
   - 点「显示全部」。

3. **选择当前显示标签（可选）**  
   - 使用「显示标签」下拉框，或「快速选择显示」按钮，或点击标签名称；  
   - 左下 / 右下三维区会切换为该标签的分析前 / 后视图。

4. **选择分析模式（可选）**  
   - 默认不勾选：仅当前分析；  
   - 勾选「结合历史记录进行分析」：与历史指标融合。

5. **开始评估**  
   点击「开始信用风险评估」，等待训练与三维渲染完成。

6. **查看结果**  
   - 四区域三维分布；  
   - 右侧准确率 / 召回率 / 精确率 / F1、识别内容与图表；  
   - 在三维场景中**单击样本球体**，查看样本编号、风险等级、特征值、置信度等。

7. **保存截图（可选）**  
   点击「保存识别截图」，或依赖分析完成后的自动保存。

8. **深入分析（可选）**  
   - 进入「图表分析」勾选图表类型并生成；  
   - 进入「日志记录 / 数据管理」查看归档；  
   - 进入「参数设置 / 系统配置」调整模型与路径。

### 7.2 三维场景操作

| 操作                  | 作用                             |
| --------------------- | -------------------------------- |
| 鼠标左键拖动          | 旋转视角                         |
| 鼠标右键拖动          | 平移场景                         |
| 滚轮                  | 缩放                             |
| 左键单击样本点        | 高亮 + 脉冲特效 + 弹出数据信息卡 |
| 点击空白处 / 关闭按钮 | 关闭信息卡                       |

### 7.3 日常运维流程

1. 在「系统配置」设定日志、图片、存储、数据库路径并保存；  
2. 在「参数设置」调整模型参数并保存；  
3. 多次运行分析后，在「数据管理」按日期查看记录、导出摘要；  
4. 在「日志记录」排查操作轨迹与识别图片。

- `log_dir` / `image_dir` / `storage_dir` / `db_path`：存储位置

## 11. 常见问题

**Q1：三维区域或图表页是空白的？**  
请确认已安装 `PyQtWebEngine`，且可访问 CDN（或检查公司网络代理）。首次加载 Three.js / ECharts 需要联网。

**Q2：点击样本没有信息卡片？**  
请先执行「开始信用风险评估」生成模型数据，再单击球体样本；过密时可略微放大后再点。

**Q3：只有一个特征时程序报错？**  
当前版本 PCA 已做特征不足时的安全补维；仍建议至少选择 2～4 个标签以获得更清晰的三维结构。

**Q4：如何恢复默认参数？**  
在「参数设置」页点击「恢复默认」，或直接编辑 / 还原 `config/settings.json`。

**Q5：能否接入真实银行数据？**  
可以。在 `core/ml_model.py` 中将 `generate_data()` 替换为真实 CSV / 数据库读取，并保持特征列与标签列接口一致即可；界面与可视化流程无需大改。
